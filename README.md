# Smart-Job-Application-Chatbot
Smart job application chatbot built using WotNot, embedded in a static website, and deployed via GitHub Pages.

# Live Demo
https://shailly-vishwakarma.github.io/Smart-Job-Application-Chatbot/

## ✨ Features
- Interactive chatbot interface 🤖
- Collects user details (name, role, experience, skills)
- Personalized responses using variables
- Clean and modern UI
- Deployed as a live website

## 🔄 Chatbot Flow
Start → Name → Role → Experience → Skill → Availability → Email → Confirmation
